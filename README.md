# Week 3 Internship Projects

## Projects Included
1. Log Analysis
2. SQL Injection Testing
3. OWASP Top 10 Overview

## 1. Log Analysis

### Objective
Analyze system logs to detect suspicious activity.

### Tasks Performed
- Collected sample log files  
- Checked for failed login attempts  
- Identified unknown IP access  

### Tools Used
- Windows Event Viewer  

### Result
Suspicious activity detected and documented.

## 2. SQL Injection Testing

### Objective
Perform manual and automated SQL injection tests on web applications.

### Tasks Performed
- Used Burp Suite for manual testing  
- Automated testing with SQLmap  
- Documented vulnerable inputs  

### Tools Used
- Burp Suite  
- SQLmap  

### Result
Identified SQL injection vulnerabilities and reported findings.

### Topics Covered
- Injection  
- Broken Authentication  
- Sensitive Data Exposure  
- Security Misconfigurations  
- And others  

### Tools Used
- Conceptual Study  

### Result
Gained knowledge of common web application vulnerabilities.
